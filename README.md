# 🌍 Travel Website — TripAdvisor-Inspired UI

A modern, visually appealing travel website inspired by TripAdvisor. This project focuses on building an engaging travel experience using **HTML5 and CSS3**, with an emphasis on responsive layouts, clean UI design, and interactive visual elements.

## ✨ Features

* 🌎 **Travel-Focused UI** — Explore travel destinations and discover places to visit.
* 🎨 **Modern UI Design** — Clean layouts, attractive visuals, and well-structured sections.
* 📱 **Responsive Design** — Media queries for mobile phones, tablets, and laptops.
* 🧱 **Flexbox Layouts** — Flexible layouts using `display: flex`, `flex-direction`, `justify-content`, `align-items`, `flex-wrap`, `gap`, and other Flexbox properties.
* 📐 **CSS Layout & Positioning** — Practical use of widths, heights, margins, padding, alignment, and box sizing.
* 🖼️ **Image Styling** — Styled travel banners, destination cards, and visual content sections.
* 🧩 **Reusable Components** — Consistent styling for navigation bars, cards, content sections, and footers.
* 📱 **Mobile-Friendly Navigation** — Adjusted layouts and spacing for smaller screens.
* 🎯 **CSS Media Queries** — Breakpoints to adapt the layout to different screen sizes.
* 🎨 **Typography & Colors** — Font styling, text alignment, spacing, and color combinations.
* 🧭 **Navigation Sections** — Organized navigation elements and search bar layout.
* 🦶 **Structured Footer** — Footer sections arranged for readability across screen sizes.
* 📦 **Box Model Practice** — Hands-on use of margins, padding, borders, widths, and `box-sizing`.
* 🛠️ **Maintainable CSS** — Organized selectors and component-based styling.

## 🛠️ Technologies Used

* **HTML5** — Page structure and semantic content.
* **CSS3** — Styling, layouts, responsiveness, and visual presentation.
* **Flexbox** — Flexible and adaptive layouts.
* **CSS Media Queries** — Responsive design for mobile, tablet, and laptop screens.
